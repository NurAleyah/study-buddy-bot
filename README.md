Module 1: Variables & Data Types
Concept: Variables act as storage containers for data.
Syntax: Use an equals sign (=) to assign a value to a name.
Text (Strings): Text requires quotation marks. Example: name = "Aleyah"
Numbers (Integers): Numbers do not require quotation marks. Example: age = 18

Module 2: The Print Function
Concept: The print() function outputs data to the screen.
Syntax: Place the data or variable you want to display inside the parentheses ().
Printing text: print("Hello World")
Printing numbers: print(100)
Printing variables: print(name)

Module 3: If/Else Conditions
Concept: Allows the code to make decisions based on specific rules.
Syntax: Use if for the primary condition and else as the fallback. Both statements must end with a colon (:), and the resulting action must be indented.
Example Code:
Python
if score > 50:
    print("You pass!")
else:
    print("Try again!")

Module 4: Python Lists
Concept: Lists store multiple items sequentially inside a single variable.
Syntax: Use square brackets [] to define the list, separating items with commas.
Example Code: cart = ["apple", "bread", "milk"]
Indexing: Python starts counting at zero. To extract the first item ("apple") from the list above, you call its position index: print(cart[0]).
